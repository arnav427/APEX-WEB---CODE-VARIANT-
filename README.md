# Findora - Intelligent Digital Lost & Found Platform

Findora is an AI-powered lost and found web application designed for campus, office, and community environments. It replaces endless scrollable lists with intelligent candidate matching, geospatial map pinning, secret verification traits, and safe custody desk handover workflows.

## 🚀 Key Features

1. **AI-Powered Candidate Matcher**: Weighted scoring algorithm matching category, appearance, location, timeline, and text similarity.
2. **Interactive Campus Map**: Geospatial SVG map with interactive pins for lost items, found reports, and custody desks.
3. **Multi-Language Selector**: Built-in instant translations across English, Spanish, French, Hindi, and German.
4. **Interactive 4-Step Report Wizard**: Guided form capturing item traits, priority levels, and secret verification answers.
5. **Privacy Shield & Anonymous Chat**: Secure direct communication without revealing personal contact numbers.
6. **Verified Handover OTP / QR Generator**: Unique one-time security codes generated for custody desk pick-ups.
7. **Dynamic Canvas Visuals**: Real-time interactive node mesh background.

## 🛠️ Quick Start Instructions

1. Extract the zip file:
   ```bash
   unzip findora-website.zip
   cd findora-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`.
