FINDORA — HACKATHON SUBMISSION

This is a self-contained front-end prototype. It uses only index.html and has no external image, font, or library dependencies.

OPEN ON ANOTHER PC
1. Submit or share Findora_Hackathon_Submission.zip.
2. On the other PC, download and extract the ZIP.
3. Open index.html in a modern browser such as Chrome, Edge, or Firefox.

SHARE A PUBLIC LINK
The C:/Users/... file path is local to the PC that created it. To give judges a URL, upload the extracted folder to a static website host or your hackathon submission platform, then share the host-provided URL. Keep index.html at the site root.

PROTOTYPE NOTES
The design, sample listings, language picker, map, chat, claim verification, and handover screens are demo interactions. There is no live database, account verification, messaging service, map provider, or real handover code. Draft saving uses browser storage when available and falls back to memory for the current tab.
